# Vocab Quiz

大学受験向けの英単語を、つづりを打ち込んで覚えるクイズアプリです。

日本語の意味が出るので、対応する英単語をキーボードで入力します。選択肢から選ぶ形式ではないので、スペルまでしっかり覚えられます。`index.html` をブラウザで開くだけで使えます。

## 使い方

1. 出題範囲を選ぶ
   - **全単語**（約 1,800 語）
   - **★ 易しい** / **★★ 標準** / **★★★ 難しい**
   - **復習** — このセッションで間違えた単語だけ
2. 表示された日本語に合う英単語を入力して `Enter`（または「解答する」）
3. 正解・不正解と答えが表示されるので、もう一度 `Enter` で次の問題へ

分からないときは「スキップ」で飛ばせます。熟語も出題され、何語の答えなのかがヒントとして表示されます（例: `2語`）。大文字・小文字は区別しません。

画面上部に正解数・解答数・正答率が出て、全問終わると最終スコアが表示されます。

## 間違えた単語の復習

間違えた単語は「間違えた単語」タブに、間違えた回数の多い順で並びます。難易度で絞り込むこともできます。出題範囲で「復習」を選ぶと、それらの単語だけをもう一度解けます。

この記録はページを閉じると消えます。

## 単語リストについて

収録する単語を選ぶにあたり、『ターゲット1900』（旺文社）を参考にしました。ただし、各単語の日本語の意味はすべて自分で作成したもので、同書の訳語や解説を転載・複製したものではありません。英単語そのものは著作権の保護対象にはあたらないと考えていますが、問題があれば Issue でお知らせください。
