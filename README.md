# Vocab Quiz

大学受験向けの英単語を、日本語の意味から英語のスペルを入力して覚えるクイズアプリです。収録語数は 1,829 語で、難易度別に出題できます。

HTML ファイル 1 つで動作し、インストールやビルドは不要です。

**デモ:** https://mimish0778.github.io/vocab-quiz/

<img src="images/screenshot.png" alt="問題に正解したときの画面" width="640">

## 特徴

- 日本語の意味を見て、英単語のスペルを入力するテスト形式
- 難易度別の出題（すべて、易しい、標準、難しい）
- 間違えた単語だけを出題する復習モード
- 正解数、解答数、正答率をリアルタイムに表示
- 間違えた単語の一覧（間違えた回数の多い順、難易度で絞り込み可能）
- 熟語や複数語の表現も収録（何語で答えるかをヒントとして表示）

## 使い方

1. [デモページ](https://mimish0778.github.io/vocab-quiz/) を開くと、すべての単語からランダムな順番で出題が始まります。
2. 上のボタンで出題範囲を選びます。

   | ボタン | 出題範囲 |
   | --- | --- |
   | 全単語 | 1,829 語すべて |
   | 易しい | 612 語 |
   | 標準 | 840 語 |
   | 難しい | 377 語 |
   | 復習 | これまでに間違えた単語 |

   難易度のボタンには、難しさに応じて 1〜3 個の星が付いています。

3. 表示された日本語に合う英単語を入力し、`Enter` キーか「解答する」で答えます。わからないときは「スキップ」で次の問題に進めます。
4. 正解と難易度が表示されます。「次の問題へ」を押して続けます。
5. 範囲内の問題をすべて解き終えると、正答率が表示されます。

「間違え一覧」タブでは、間違えた単語と間違えた回数を確認できます。

### 判定のルール

- 大文字と小文字は区別しません。前後の空白も無視します。
- それ以外は、正解の綴りと完全に一致した場合だけ正解になります。
- スキップした問題は解答数に数えません。
- 出題範囲を切り替えると、正解数と正答率はリセットされます。

間違えた単語の記録はページの中にだけ保持され、ページを閉じたり再読み込みしたりすると消えます。

### ローカルで動かす

```bash
git clone https://github.com/mimish0778/vocab-quiz.git
```

クローンした `index.html` をブラウザで開くだけで使えます。

## 単語データ

単語は `index.html` の `ALL_WORDS` に、次の形式で収録しています。`diff` は難易度（1: 易しい、2: 標準、3: 難しい）です。

```js
{jp:"達成する",en:"achieve",diff:1},
```

## 技術構成

- HTML / CSS / JavaScript（ライブラリやフレームワークは不使用）
- フォント: [Noto Serif JP](https://fonts.google.com/noto/specimen/Noto+Serif+JP)、[Playfair Display](https://fonts.google.com/specimen/Playfair+Display)、[JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)（Google Fonts）

## 著作権について

単語リストを作るにあたり、収録する語彙を選ぶ参考として『ターゲット1900』（旺文社）を参照しました。ただし、各英単語に対応する日本語の意味はすべて独自に作成したもので、同書の訳語や解説を転載・複製したものではありません。英単語そのものは著作権の保護の対象にはあたらないと解されており、本アプリは著作権の侵害を意図したものではありません。

問題がある場合は、Issue でご連絡ください。
